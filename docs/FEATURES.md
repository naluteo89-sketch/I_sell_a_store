## 1. 영상 ↔ 상품 연결
- **상태**: ✅ · **마지막 변경**: 2026-11-12
- **동작**
  - 상품 상세 오른쪽에 리뷰 영상 패널. 썸네일 목록만 보이다가 [실행하기]를 누를 때 YouTube 플레이어(iframe)를 만든다 → 누르기 전에는 유튜브로 데이터가 가지 않음
  - 방문자 조회는 DB 캐시만 읽음, 유튜브 검색은 상품 등록 시 1회 + 매일 스케줄러
  - 30일 넘은 검색 결과는 비움 (유튜브 정책)
  - 광고는 YouTube가 결정 — 사이트에서 막지 않음 (개발자 정책)
- **코드 위치**: `backend/.../youtube/`, `frontend/views/youtube/YoutubePanel.tsx`
- **API**: `GET /api/products/{id}/videos`

## 2. 보는 방식 선택
- **상태**: ✅ · **마지막 변경**: 2026-11-13
- **동작**
  - 목록 위 `상품별 / 영상별` 전환, 선택은 쿠키 `listView`에 저장
  - 영상별: 한 영상에 나온 상품을 묶어 보여 줌 (상품 미리보기 + "상품 N개")
  - 정렬 — 상품별: 최신 · 리뷰 조회수 · 유튜버 인기 · 가격 · 이름 / 영상별: 리뷰 조회수 · 유튜버 인기 · 최신
- **코드 위치**: `frontend/views/product/ViewToggle.tsx`, `ListToolbar.tsx`, `lib/productList.ts`, `backend/.../catalog/VideoCollectionService.java`
- **API**: `GET /api/videos?lang=&category=&sort=&page=&limit=` (총 개수는 `X-Total-Count` 헤더)

## 3. 빠른 보기 · 장바구니에 담기
- **상태**: ✅ · **마지막 변경**: 2026-11-13
- **동작**
  - 카드 가격 옆 장바구니 아이콘 → 옵션·수량을 고르는 시트(`<dialog>`), 카드 나머지 영역을 누르면 상세 페이지
  - 라벨: 한국어 "장바구니에 담기" / 영어 "Give it to me"
  - 마우스를 올리면 아이콘에 작은 상자가 담기는 효과
  - 시트가 열려 있을 때는 배경 스크롤·키보드 페이지 이동 중지
- **코드 위치**: `frontend/controllers/useQuickView.ts`, `views/quickview/QuickViewSheet.tsx`, `views/gimme/`

## 4. 언어 = 시장
- **상태**: ✅ · **마지막 변경**: 2026-11-13
- **동작**
  - 한국어 → 한국 상품·유튜버(4,433개), 영어 → 영미권 상품·유튜버(9,276개), 겹침 없음
  - 언어 결정 순서: 직접 고른 값(쿠키) → 브라우저 언어 → 접속 국가(배포 환경 헤더) → 한국어
  - 사이트 이름: 한국어 "하우머치" / 영어 "you_HOWMUCH"
  - 한국어 화면은 기본 고딕, 개성 있는 제목 글꼴은 영어 화면에서만
- **코드 위치**: `frontend/lib/i18n/` (config · dictionaries · server), `models/api/siteApi.ts`
- **규격**: `frontend/docs/market-api.md`

## 5. 유튜브 제품 자동 수집
- **상태**: 🚧 · **마지막 변경**: 2026-11-12
- **동작**
  - 검색어별로 유튜브를 페이지마다 이어 검색 → 영상 설명란의 제품 목록을 상품으로 등록
  - 가격이 없으면 테스트 가격 7,701원 (`priceSource = TEST`)
  - 실적: 영상 2,488개 · 유튜버 1,654명 → 상품 13,709개
- **남은 일**: 상품명 필터(설명란 문구 유입), 따옴표 보존, 카테고리 판정, 가격 추출 보완, 기존 데이터 정리
- **코드 위치**: `backend/.../sourcing/`
- **API**: `POST /api/admin/sourcing/start|stop`, `GET /api/admin/sourcing/status`

## 6. 빠른 목록 · 페이지 이동
- **상태**: ✅ · **마지막 변경**: 2026-11-13
- **동작**
  - 상품 40개씩 서버에서 잘라 받음 → "전체" 페이지 10.7MB → 116KB, DB 쿼리 50~80ms
  - 넓은 화면은 목록 양옆 `‹ ›`, 아래쪽 페이지 번호, 키보드 `←` `→` (입력 중이거나 창이 열려 있으면 무시)
  - 넘긴 방향으로 미끄러지는 전환 + "N 페이지" 표시. 전체 페이지 수는 보여 주지 않음 (상품 규모 비노출)
  - 상품별·영상별 보기 모두 적용
- **코드 위치**: `frontend/controllers/usePager.ts`, `views/product/PagedResults.tsx`, `models/api/http.ts`(`getPage`)

## 7. 상품별 썸네일 장면 배정
- **상태**: 🚧 · **마지막 변경**: 2026-11-13
- **동작**: 같은 영상에서 나온 상품마다 다른 장면(hq720 · maxres1~3) + 자르기 위치를 배정 → 13,709개 이미지 중복 0
- **남은 일**: 쇼츠(세로 영상) 썸네일은 좌우 자르기에 검은 띠가 걸림 → 가운데 확대로 변경
- **코드 위치**: `backend/.../catalog/FrameImageAssigner.java`, `backend/db/frame-images.sql`, `frontend/lib/productImage.ts`

## 8. 회원 · 자동 닉네임
- **상태**: ✅ · **마지막 변경**: 2026-11-13
- **동작**
  - 이메일 + 비밀번호 가입 (이름 입력 없음)
  - 닉네임: 형용사 + 동물 + 숫자 4자리 자동 생성(한/영), 가입 화면에 미리 보여 주고 실시간 중복 확인, 🔄 다시 뽑기, `내 계정`에서 변경
  - 서버 세션(HttpOnly 쿠키) · PBKDF2-SHA256 · 로그인 API CSRF 검사 · 5분 10회 실패 차단 · 로그인 유지 14일
  - 로그인 실패 문구로 가입 여부를 알려 주지 않음
- **코드 위치**: `backend/.../member/`, `frontend/views/auth/`, `controllers/useAuthForms.ts`
- **규격**: `frontend/docs/auth-api.md`

## 9. SSO
- **상태**: 🚧 · **마지막 변경**: 2026-11-13
- **동작**: 버튼·흐름(프론트)과 백엔드 규격 준비 완료. 키가 없는 제공자 버튼은 숨김
- **남은 일**: 카카오·네이버·Google·Apple 키 발급 → Spring Security OAuth2 Client 연결
- **코드 위치**: `frontend/lib/auth/providers.ts`, `views/auth/SsoButtons.tsx`

## 10. 테마
- **상태**: ✅ · **마지막 변경**: 2026-11-13
- **동작**
  - 기본 다크 고딕(블랙 + 크림슨 #DC143C), 라이트 화이트 초콜릿(크림 + 브라운)
  - 선택은 쿠키에 저장 → 첫 화면부터 깜빡임 없이 적용
  - 모든 글자·배경 대비 4.5:1 이상(계산으로 확인)
  - 절제 원칙: 빛번짐·광택 없이 얇은 선과 명도 차이로 구분, 상품 글씨는 기본 고딕
- **코드 위치**: `frontend/styles/tokens.css`, `lib/themeMode.ts`, `views/layout/ThemeToggle.tsx`
